# Expense Tracker CLI



A simple, modular Command Line Expense Tracker built using Python.

This project helps users record, view, update, and analyze daily expenses using a clean CLI interface and CSV-based storage.



The project is designed to strengthen core Python fundamentals such as file handling, modular programming, data validation, and basic data analysis.



## Features



- Add new expense records



- View all stored expenses



- Update existing expense entries



- Delete expense records



- Calculate total expenses



- Store data persistently using CSV files



- Input validation for dates and numeric values



- Clean, menu-driven CLI interface



## Project Structure





- main.py           --> Entry point of the application

- storage.py       --> Handles file operations (read/write/update)

- expense.py       --> Expense-related logic and data structure

- utils.py         --> Helper functions (validation, formatting)

- expenses.csv     --> Expense data storage (auto-created)

- README.md        -->Project documentation

## Technologies Used

- Python 3

- Standard Libraries:

    - csv

    - datetime

    - os

No external dependencies are required.
